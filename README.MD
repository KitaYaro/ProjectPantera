# ProjectPantera

## Описание

ProjectPantera - это учебный веб-проект на Java Servlets, демонстрирующий веб-приложение с функциональностью регистрации, авторизации, игровой механикой квеста и отслеживанием статистики.

## Технологии

- Java 21
- Jakarta Servlet API
- JSP (JavaServer Pages)
- Hibernate ORM
- PostgreSQL
- Maven
- JUnit 5
- Mockito
- Lombok
- Logback

## Структура проекта

```
src/main/java/
```

## Основные особенности

### Архитектура
- Применен паттерн Front Controller для централизованной обработки запросов
- Используется Dependency Injection для слабой связанности компонентов
- Разделение ответственностей: контроллеры, сервисы, репозитории, сущности
- Утилитные классы для повторно используемой функциональности
- DAO pattern для абстракции доступа к данным

### Функциональность
- Регистрация и авторизация пользователей
- Хеширование паролей для безопасности
- Игровой квест "Путь дракона" с системой доверия и этапами
- Отслеживание и отображение статистики пользователей
- Защищенные маршруты requiring authentication
- Поддержка международнойization (потенциально через JSP)

### Качество кода
- Использованы константы для всех магических строк и чисел
- Комплексное логирование с разными уровнями (SLF4J + Logback)
- Обработка исключений с кастомными типами исключений
- Юнит-тесты с использованием JUnit 5 и Mockito
- Соответствие принципам SOLID
- Использование Lombok для уменьшения boilerplate кода

## Настройка и запуск

### Требования
- JDK 21
- Maven 3.6+
- PostgreSQL
- Tomcat 10+ (или другой servlet контейнер)

### Шаги запуска
1. Настройте PostgreSQL базу данных согласно настройкам в `src/main/resources/hibernate.cfg.xml`
2. Выполните `mvn clean package` для сборки WAR файла
3. Разверните полученный WAR файл в Tomcat
4. Откройте браузер и перейдите по адресу `http://localhost:8080/`

### Тесты
Запустите все тесты командой:
```
mvn test
```

Для просмотра отчёта о покрытии кода:
```
mvn verify
```
Затем откройте `target/site/jacoco/index.html` в браузере.
